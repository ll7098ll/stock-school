## [1.0.0] - 2026-05-20

### 🎉 최초 릴리즈

### ✨ 추가됨 (Added)

#### 인증 & 사용자 관리
- Google OAuth 2.0 소셜 로그인 (Firebase Authentication)
- 게임 상태 자동 저장/복원 (Firebase Firestore)
- 사용자별 독립 게임 세션

#### 게임 시스템
- 3단계 난이도 시스템 (초등학생/중학생/고등학생)
- 난이도별 초기 자금 (100만원/500만원/1,000만원)
- 일(Day) 단위 시뮬레이션 진행 시스템

#### 주가 시뮬레이션
- 5가지 요소 기반 주가 시뮬레이션 엔진
  - 시장 요인, 뉴스 임팩트, 랜덤 변동성, 평균 회귀, 충격 이벤트
- 일일 변동 ±15% 제한
- 30개 한국 실제 기업 종목 (14개 섹터)

#### 거래 시스템
- 매수/매도 주문 실행
- 평균 매수가 자동 계산
- 잔고/보유량 검증
- 호가창 시뮬레이션

#### 뉴스 시스템
- 60+ 뉴스 이벤트 (난이도별 필터링)
- 뉴스 → 섹터 → 주가 연동
- 4개 카테고리 (거시경제/산업/기업/글로벌)
- 다음 날 AI 해설 공개 시스템

#### 포트폴리오
- 보유 종목 관리
- 수익률 추적
- 자산 추이 차트 (Recharts)
- 자산 배분 파이 차트

#### 학습 도구
- 금융 용어 사전 (16개 핵심 용어)
- 난이도별 용어 설명
- 기업 분석 패널 (난이도별 설명)
- 인터랙티브 8단계 튜토리얼 ("스탁 쌤")

#### UI/UX
- 다크/라이트 테마 전환
- TradingView 기반 가격 차트 (Lightweight Charts)
- 반응형 레이아웃 (모바일/데스크톱)
- 섹터별 필터링 & 종목 검색
- 미니 스파크라인 차트

#### 개발 인프라
- React 19 + TypeScript 6 + Vite 8
- TailwindCSS 4 + shadcn/ui
- Zustand 5 상태 관리
- ESLint 10 코드 검사
