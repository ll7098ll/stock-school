## [2.1.0] - 2026-11-23

### 🎯 경제 문해력 전면 개편 & 1,098편 콘텐츠 확장

### ✨ 추가됨 (Added)
- **무스포일러 경제 문해력 학습 루프**: 당일 뉴스룸·종목 리스트·포트폴리오·미완료 시나리오에서 관련 산업/종목 자동 힌트를 전면 제거하고, 학생이 직접 **① 영향 산업 추론(1~3개) + ② 방향 예측** 후 다음 날 이중 채점으로 복기하는 시스템 도입
- **학생 주도 `★ 관심 종목` (Watchlist)**: 뉴스에서 추론한 기업을 직접 별표로 모아 보고 기업 정보와 대조하는 기능 추가
- **6종 기사 포맷 & 리치 블록**: `속보·단독`, `실적·공시`, `현장 인터뷰`, `라이벌 대조`, `정책 브리핑`, `생활경제 르포` 포맷과 핵심 수치 카드(`keyMetrics`), 현장 인용구(`quote`), 본문 연동 용어 칩(`relatedGlossaryIds`) 도입
- **콘텐츠 대폭 확장 (843편 → 1,098편)**:
  - 공백 5대 테마(인구구조·계절성·사이버보안·자본시장 메커니즘·미디어 리터러시) 신규 단독 기사 **90편** (`diverseThemesNews.ts`)
  - 34개 전 종목 균형 보강 개별기업 기사 **34템플릿 / 102편** (`companyNewsBalanced.ts`)
  - 소외 종목 주연 신규 멀티데이 시나리오 **6종 / 21화 / 63편** (`diverseNewScenarios.ts`, 총 30종 시나리오)
- **금융 용어 사전 확장 (18개 → 32개)**: `컨센서스`, `어닝 서프라이즈/쇼크`, `자사주 소각`, `NIM`, `CapEx`, `수주잔고`, `정제마진`, `래깅 효과`, `물적분할/중복상장`, `CB·오버행`, `액면분할`, `CDMO`, `밸류업`, `리스크 오프` 추가

### 🔧 수정됨 (Fixed)
- **전수 정화**: 잔존 실기업명·브랜드·파손어(`강철산업퓨처엠` 등), 한국어 조사 오류 351건+, 중복 종목명 16건+ 0건 정화 및 `verifySimulation.mjs` 자동 검증 강제
- **정합성·엔진 복구**: 기사↔종목 불일치 유령 오버라이드 48건, 시나리오 `stockImpactOverrides` 역전 버그 150건, `sentiment` 불일치 37건 수정 및 `simulateNextDay`의 `news.marketBias` 실제 반영
- **기본 기사 102편 리마스터**: 2문장 요약을 비스포일러 4~5문장 기사로 확장하고 전원에 `twistType`·`readingHint`·메타데이터 완비

## [1.0.0] - 2026-05-20

### 🎉 최초 릴리즈

### ✨ 추가됨 (Added)

#### 인증 & 사용자 관리
- Google OAuth 2.0 소셜 로그인 (Firebase Authentication)
- 게임 상태 자동 저장/복원 (Firebase Firestore)
- 사용자별 독립 게임 세션

#### 게임 시스템
- 3단계 난이도 시스템 (초등학생/중학생/고등학생)
- 난이도별 초기 자금 (100만원/500만원/1,000만원)
- 일(Day) 단위 시뮬레이션 진행 시스템

#### 주가 시뮬레이션
- 5가지 요소 기반 주가 시뮬레이션 엔진
  - 시장 요인, 뉴스 임팩트, 랜덤 변동성, 평균 회귀, 충격 이벤트
- 일일 변동 ±15% 제한
- 30개 한국 실제 기업 종목 (14개 섹터)

#### 거래 시스템
- 매수/매도 주문 실행
- 평균 매수가 자동 계산
- 잔고/보유량 검증
- 호가창 시뮬레이션

#### 뉴스 시스템
- 60+ 뉴스 이벤트 (난이도별 필터링)
- 뉴스 → 섹터 → 주가 연동
- 4개 카테고리 (거시경제/산업/기업/글로벌)
- 다음 날 AI 해설 공개 시스템

#### 포트폴리오
- 보유 종목 관리
- 수익률 추적
- 자산 추이 차트 (Recharts)
- 자산 배분 파이 차트

#### 학습 도구
- 금융 용어 사전 (16개 핵심 용어)
- 난이도별 용어 설명
- 기업 분석 패널 (난이도별 설명)
- 인터랙티브 8단계 튜토리얼 ("스탁 쌤")

#### UI/UX
- 다크/라이트 테마 전환
- TradingView 기반 가격 차트 (Lightweight Charts)
- 반응형 레이아웃 (모바일/데스크톱)
- 섹터별 필터링 & 종목 검색
- 미니 스파크라인 차트

#### 개발 인프라
- React 19 + TypeScript 6 + Vite 8
- TailwindCSS 4 + shadcn/ui
- Zustand 5 상태 관리
- ESLint 10 코드 검사
