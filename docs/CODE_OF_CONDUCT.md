# 📜 행동 강령 (Code of Conduct)

## 🤝 우리의 서약

우리는 프로젝트의 구성원, 기여자, 리더로서 연령, 신체 크기, 장애 유무, 민족, 성 정체성, 경험 수준, 교육 수준, 사회경제적 지위, 국적, 외모, 인종, 종교, 또는 성적 정체성과 지향에 관계없이 **모든 사람에게 괴롭힘 없는 커뮤니티** 경험을 제공할 것을 서약합니다.

## 📋 우리의 기준

### ✅ 긍정적 환경에 기여하는 행동

- 🤗 환영하고 포용적인 언어 사용
- 🎯 다양한 관점과 경험 존중
- 💬 건설적인 비판의 정중한 수용
- 🌟 커뮤니티에 가장 좋은 것에 초점
- 💕 다른 커뮤니티 구성원에 대한 공감

### ❌ 허용되지 않는 행동

- 🚫 성적인 언어나 이미지 사용, 원치 않는 성적 관심이나 접근
- 🚫 트롤링, 모욕적/비하적 댓글, 개인적 또는 정치적 공격
- 🚫 공적 또는 사적 괴롭힘
- 🚫 명시적 동의 없는 타인의 개인정보 공개
- 🚫 전문적 환경에서 부적절하다고 판단되는 기타 행위

## 🔨 시행

학대, 괴롭힘 또는 기타 허용되지 않는 행동이 발생할 경우, 프로젝트 관리자에게 GitHub Issues를 통해 보고해 주세요.

모든 불만 사항은 검토 및 조사되며, 상황에 적절하고 필요하다고 판단되는 대응이 이루어질 것입니다.

## 📌 적용 범위

이 행동 강령은 모든 프로젝트 공간에서 적용되며, 개인이 공개적으로 프로젝트나 커뮤니티를 대표할 때에도 적용됩니다.

## 📖 출처

이 행동 강령은 [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)을 기반으로 작성되었습니다.
